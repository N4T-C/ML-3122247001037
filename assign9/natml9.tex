                                                prediction = np.argmax(scores)

                                                actual = y[i]

                                                if prediction != actual:

                                                   self.weights[actual] += ( self.learning_rate * X[i])

                                                   self.weights[prediction] -= (self.learning_rate * X[i])

                                                   self.bias[actual] += self.learning_rate

                                                   self.bias[prediction] -= self.learning_rate

                                                   errors += 1

                                        self.errors.append(errors)

                                        print("Epoch",epoch + 1,"Errors:",errors)

                                  return self

                            def predict(self, X):

                                  scores = np.dot(X,self.weights.T) + self.bias

                                  return np.argmax(scores, axis=1)

4     Justification for Chosen Hyperparameters
For the MLP model, different hyperparameter values were considered for the learning rate, batch size,
optimizer, activation function, and network size. The final configuration was selected based on the training
performance and stability observed during the tuning process.

    • Activation Function – ReLU:
      ReLU was used in the hidden layer as it allows the network to learn nonlinear patterns and is suitable
      for recognizing the different shapes and structures present in handwritten characters.
    • Optimizer – Adam:
      The Adam optimizer was selected because it provides adaptive learning rates and generally provides
      stable and efficient convergence during training.
    • Learning Rate – 0.001:
      A learning rate of 0.001 was chosen as it provides a suitable balance between learning speed and training
      stability.
    • Batch Size – 32:
      A batch size of 32 was used to provide a reasonable balance between computational efficiency and
      model performance.
    • Hidden Layer – 128 Neurons:
      One hidden layer with 128 neurons was used to provide sufficient capacity for learning the character
      patterns while keeping the model relatively simple.
    • Number of Epochs – 30:
      The model was trained for 30 epochs to provide sufficient training time for the network to learn the
      features from the handwritten character images.
